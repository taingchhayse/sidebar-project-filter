# Sidebar Project Filter

Sidebar Project Filter adds a search field above Paseo's sidebar workspace controls. Type part of a project name or its project key to show only matching project groups and their workspaces.

The filter is case-insensitive and applies immediately as you type. Escape or the clear button restores every project. The query is held only in memory.

The plugin runs in Paseo desktop and web clients. It uses the sidebar's rendered project rows and does not send data over the network or modify project data.
